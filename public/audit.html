What we did

  • Censoring: unresolved incidents carry elapsed hours, not fix time.
  • Winsorise durations at 1st/99th pct: avg resolution hours range 10–66 → 16–54.
  • RobustScaler (median/IQR) on skewed features: weighted severity 6–47 → −1.2…1.9.
  • Duplicates 0 · orphan IDs 0 · missing 0.
  • Ordinal weights: severity L1/M2/H4/C8; priority L1/N2/H4.

03 · Pipeline

Validate & clean. Duplicates, orphan location_ids, missing values; unresolved incidents are right-censored; durations winsorised.
Features at an as-of date. Only events before the date are used (no leakage). Severity load decays with a 120-day half-life.
Shrinkage. (n·raw + 3·zone_mean)/(n+3) pulls sparse locations toward their zone average.
Score. Six components → percentile 0–100 → weighted sum.
Bootstrap. 200 Poisson reweights → rank interval and chance of staying top 50.
Explain. Top-3 reasons, confidence label, missing-info flags, suggested crew.
